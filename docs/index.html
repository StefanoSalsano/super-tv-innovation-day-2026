The talk

SUPER develops open-source components that converge into a sovereign, high-availability cloud platform without proprietary lock-in, with GPU sharing for AI workloads.

  • FIGO — Federated Infrastructure for GPU Orchestration: dynamic GPU allocation to VMs and containers, with priority for GPU owners. github.com/StefanoSalsano/figo
  • SHARY — SHaring Any Resource made easY: one web front end (Prognose) to book GPUs, SmartNICs and P4 switches of the RESTART testbed; GPU reservations are enforced through FIGO.
  • PASTRAMI — Performance Assessment of SofTware Routers Addressing Measurement Inaccuracy: reliable PDR@0.5% measurements in virtualized environments. github.com/netgroup/pastrami
  • eFFECT — per-flow monitoring in the Linux kernel with eBPF, with metrics in Prometheus and Grafana.
  • Nano-f — Tor Vergata spin-off bringing these results to market.
